# Rosetta — screens

Rosetta has **no user interface**: it is an HTTP service speaking MCP, plus a few
machine endpoints (`/health`, `/`, `/.well-known/oauth-protected-resource`, OAuth
callbacks of the user-data addons). No screen `E-n` exists and this epic adds none.
Every human gesture of the journeys (`docs/parcours.md`) is a file edit, a command or
a pull request.
